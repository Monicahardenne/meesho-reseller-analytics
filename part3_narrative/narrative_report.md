# Chart Choice Justification

## Question 1: Which month had the highest total revenue?

Values:

- April = INR 419417.43
- May = INR 444594.25
- June = INR 398055.24

Recommended Chart: Bar Chart

Justification:

This is a bivariate comparison because it compares revenue across different months. A bar chart allows viewers to determine the highest month within a few seconds. The y-axis should start at zero to avoid exaggerating differences. A 3D chart should be avoided because it makes comparison difficult. Since there is only one measure, a legend is not required.
